Verification passes only when the locally calculated SHA-256 and size of every GitHub Pages file match the live wallet file exactly.

Scope of this verification

A successful result means the frontend bytes returned to this browser by app.tscweb.xyz matched the independently hosted GitHub Pages build for the displayed commit at the time of this request. A hostile server can still vary responses by client or request, so this does not replace source review or prove that DNS, TLS, browser extensions, or the user’s device are secure.
